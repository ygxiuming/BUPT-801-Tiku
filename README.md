# 北邮801通信原理 · 真题库

北京邮电大学硕士研究生招生考试 **801 通信原理** 历年真题的结构化题库、Vue 刷题网站与在线 PDF 排版服务。

## 快速启动

```bash
# 1. 刷题网站（Vue 3 + Vite）
cd app && npm install && npm run dev     # http://localhost:5173

# 2. 后端服务（静态托管 + 在线 PDF 排版，另需先构建前端）
cd app && npm run build
cd ../server && npm install && npm start  # http://127.0.0.1:3000
```

开发模式下 Vite 自动把 `/api` 代理到本地 3000 端口；生产部署只需跑 `server`（托管 `app/dist`）。

| 页面 | 地址 | 功能 |
|---|---|---|
| 首页 | `/` | 学习总览：逐年真题进度、继续上次、考点覆盖、功能入口 |
| 试卷页 | `/paper/2025` | 统一版式真题 + **章节目录导航**，可开关答案解析；**在线 PDF 下载**（服务端 Puppeteer 排版）+ 浏览器打印 |
| 刷题站 | `/practice` | 按**年份 / 题型 / 章节→知识点 / 易错点 / 收藏**筛选刷题；选择题点选即判+逐选项解析；大题分步推导+三档掌握度自评（会/模糊/不会）；题目收藏、相关题目推荐、**键盘快捷键**、**题目深链** (`?id=`)、移动端筛选抽屉；解析可随时隐藏 |
| 模拟测试 | `/exam` | 倒计时+答题卡+标记存疑，交卷自动判分+**按各题实际分值自评**，全卷回顾（可只看错题）；**中断自动保存**，刷新后可继续 |
| 做题统计 | `/stats` | 总正确率、分章正确率、**掌握度环形图**、**近 14 天作答活跃度**、错题本与收藏清单一键重练/单题直达 |
| 图库 | `/figures` | 全部 SVG 框图，按年份/题目原图/解析配图分组，支持关键词搜索 |

**界面**：浅色 / 深色主题切换（跟随系统，选择记忆在 localStorage）；右上角「?」查看全站快捷键与数据说明；窄屏下筛选栏收进抽屉。

**交互**：题图（SVG 框图）点击即全屏放大，滚轮缩放、拖拽平移、双击复位、Esc/✕ 关闭。

做题记录与收藏保存在浏览器 localStorage（键 `bupt801-records-v1`），模考进度存 `bupt801-exam-v1`。

## 目录结构

```
待解析/                     # 原始PDF与答案图片（输入，不参与网页）
data/
  chapters.js               # 两级章节→知识点体系（全站筛选维度）
  figures/<年>/             # SVG图库：单图一文件（题目原图 + answer/ 解析配图 + _index.js 索引）
  questions/<年>/           # 题库：paper.js（真题：元数据+groups+题干选项）+ answer.js（答案与解析，按题目 id）
app/                        # Vue 3 前端（vite；npm run sync 同步 data 与 KaTeX 到 public/）
  src/styles/app.css        # 全站设计系统：浅/深色令牌 + 组件样式（改配色只动文件头令牌区）
  src/views/                # 5 个页面：首页 / 试卷 / 刷题 / 模考 / 统计 / 图库
  src/components/           # 题目卡、答题卡、解析、图块、放大弹窗、图标、进度环、提示条、帮助弹窗
  src/lib/                  # data 访问、records 记录、KaTeX 渲染、lightbox、theme、toast
server/                     # Express：托管 app/dist + /api/pdf/<年>/(paper|ans) 在线排版
skills/bupt801/SKILL.md     # 新年份入库的解析流程技能
解析日志.md                 # 每年入库/改题/重画图的记录（来源、统计、校验、纠错、遗留）
tools/                      # 图库生成脚本 + 数据校验 + 页面冒烟（validate_data.js 零错误才算完成）
```

## 版本管理

仓库用 git 管理，**一个年份一个提交**，入库/改题/重画图完成后立即提交并在 `解析日志.md` 追加一条记录。

```bash
git status --short
git add data/questions/<年> data/figures/<年> app/index.html tools/ 解析日志.md
git commit -m "feat(<年>): 入库 <年> 真题（50 空 + 8 大题 + 16 图）"
```

`node_modules/`、`app/dist/`、`app/public/` 已进 `.gitignore`（都能用 `npm install` / `npm run sync` 再生成）。

## 答案可信度

每份答案经**三重交叉验证**：AI 独立推导 ✓ 参考解析 ✓ 手写批注核对 ✓。
个别与参考资料不一致处（如 2025 年第 30 题）均按严格推导定论，并在解析中写明差异理由。

## 新增年份

把新年份的试卷 PDF 与答案（PDF/图片）放入 `待解析/`，然后按 `skills/bupt801/SKILL.md` 的流程执行：转录 → 定答案 → 写解析 → SVG → 校验 → 页面冒烟 → **追加 `解析日志.md`** → **git 提交**。其中最后两步不要省，`app/index.html` 也要登记新数据 `<script>`（`app/scripts/sync-data.mjs` 会自动同步 data/ 全部文件）。
