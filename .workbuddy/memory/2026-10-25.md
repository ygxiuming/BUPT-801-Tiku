# 2026-10-25 · 前端界面改版（布局优化 / 功能补齐 / 视觉美化）

## 做了什么

对 `app/src` 做了一次整体重构，数据契约与 KaTeX 渲染规则不变，只动视图层。

- **设计系统重写**（`app/src/styles/app.css`，约 1100 行）：设计令牌（浅/深两套）→ 基础排版 →
  顶栏/页脚 → 通用组件 → 首页 → 试卷 → 题目卡 → 侧栏 → 模考/统计 → 图库 → 灯箱 → 响应式 → 打印。
  主色仍是蓝，但换成 #2f5dfd 系；卡片 16px 圆角 + 双层柔和阴影；正文 15px/1.7，题干用宋体。
- **新增能力**
  - 深/浅主题切换（`lib/theme.js`，`html[data-theme]` + localStorage，默认跟随系统）
  - 全站提示条 `lib/toast.js` + `Toast.vue`（收藏、清空记录、交卷）
  - 图标组件 `Icon.vue`（24×24 stroke 图标表），替换 emoji
  - `ProgressRing.vue` 环形进度（成绩页得分率）
  - `HelpModal.vue` 快捷键/数据说明弹窗（顶栏 ? 按钮、页脚入口）
  - 题目深链 `/practice?id=<qid>`（首页「继续上次」、统计页错题/收藏直达）
- **布局**
  - 首页：Hero（网格纹理+光晕）+ 继续上次 + 逐年进度卡（进度条）+ 考点覆盖条形图 + 工具入口
  - 试卷页：目录侧栏（滚动高亮）+ 吸顶工具条（解析开关/打印/PDF）
  - 刷题页：吸顶工具条（题号/进度/上下一题/收藏/筛选）+ 窄屏筛选抽屉
  - 模考页：设置页卡片化、按各题实际分值自评（修掉「30 题/30 分」「15 分」硬编码，2026 是 40 空、第二题 20 分）
  - 统计页：KPI 四卡 + 掌握度环形图 + 近 14 天活跃度 + 分章正确率（按 <50 / <75 着色）+ 错题/收藏单题直达
  - 图库页：年份筛选 + 关键词搜索
- **样式约定**：组件不再写 `<style scoped>`，样式统一进 `app.css`；`.paper-sheet` 内部锁定浅色令牌，
  保证深色主题下卷面仍是白纸黑字；`.figblock` 永远白底（SVG 是深色线条）。

## 构建 / 验证

- 本机 `vite build` 失败：`WebAssembly.instantiate(): Out of memory`（rollup 内置 xxhash wasm 需要预留地址空间，
  而进程 `ulimit -v` 是 4GB）。因此新增 `tools/build-frontend.mjs`：esbuild + `@vue/compiler-sfc` 直出
  `app/dist/index.html` + `assets/app.{js,css}`，已跑通。
- 无浏览器（headless Chrome EXIT=133），验证改为 **jsdom 冒烟**：加载 data 脚本 → 挂载 App → 逐页导航 →
  点选项/看解析/收藏/开始考试/标记/交卷/试卷解析开关/图库搜索，40+ 断言全过，且 `window.__vueErrors` 为空；
  对打包产物 `dist/assets/app.js` 另跑一遍导航，全过。
