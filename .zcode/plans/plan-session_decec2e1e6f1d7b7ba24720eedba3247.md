# 北邮801通信原理 题库网页 + 解析Skill 方案

## 一、现状确认
- 试卷PDF（6页）：封面+5页，30道选择题（**多题共用一组ABCD选项**的填空式）+ 8道大题×15分 = 150分，含3处框图（SSB解调、PAM系统、(7,4)编码器）
- 答案PDF（20页）：**红笔手写批注**——选择题仅标答案字母、大题为跳步手写推导，无文字解析，个别字迹潦草
- 结论：手写答案只能当参考，详细解析需AI独立解题后与手写答案交叉校验

## 二、目录架构
```
北邮801-通信原理/
├── 待解析/                    # 原始PDF（试卷+答案），按年份放入
├── skills/bupt801/SKILL.md    # 解析流程skill（软链到 ~/.agents/skills/ 供ZCode识别）
├── data/
│   ├── chapters.json          # 两级章节→知识点定义
│   ├── papers.json            # 试卷索引（年份/题量/考点统计）
│   └── questions/2025.js      # 结构化题库（含答案+详细解析，做成.js避免file://下fetch跨域问题）
├── web/
│   ├── index.html             # 展示站首页：按年份列真题（GitHub Pages用）
│   ├── paper.html?y=2025      # 真题在线查看：统一版式+答案解析开关+打印按钮
│   ├── practice.html          # 刷题应用（完整功能）
│   ├── css/  js/
│   ├── vendor/katex/          # 公式渲染本地化，离线可用
│   └── assets/svg/            # 试卷框图SVG
└── README.md
```
两套前端共用同一份题库数据与渲染组件：**展示站**只有试卷浏览/打印（部署GitHub Pages）；**刷题站**是完整刷题体验。

## 三、题库数据模型（2025.js）
- `sharedOptions`：选择题共享选项组，如 (1)(2)(3) 共用一组ABCD
- 选择题：题干（空格编号加粗）、答案、**逐选项详细解析**（正确依据+每个错误项排除理由+知识点回顾）、章→知识点、易错点标签
- 大题：题干+小问、**分步推导解析**（KaTeX公式、中间数值）、每问最终答案、易错提醒、章→知识点
- SVG图：试卷3张框图 + 解析配图（8PSK星座图、概率转移图等）按需绘制，统一风格

## 四、答案准确性策略
1. 辨认答案PDF手写内容（选择题字母、大题数值结论）
2. AI按通信原理**独立解题**写详细解析
3. 交叉校验：一致→定稿；不一致→复核推导，以推导为准并在解析中说明

## 五、章节体系（chapters.json，两级）
ch1 随机信号分析 / ch2 模拟调制 / ch3 数字基带传输 / ch4 数字带通传输 / ch5 信源编码 / ch6 差错控制编码 / ch7 信息论基础 / ch8 同步原理 / ch9 最佳接收；每章下再细分知识点（如 ch4→8PSK星座图、OFDM、MQAM），2025各题解析时实际标注映射。

## 六、网页功能
**展示站**：年份列表 → 试卷页统一真题版式（标题/注意事项/分节/页脚“考试科目：801通信原理 第X页共Y页”），KaTeX+SVG渲染；答案解析开关；打印CSS（A4分页、默认隐藏答案）→ Ctrl+P 存PDF即按年份下载试卷。
**刷题站**：筛选（年份/题型/章节→知识点/易错点）；选择题点选即判+展开逐选项解析；大题先思考后逐小问展开；错题本+错题重练（localStorage）；正确率统计（总体/分章）；整卷模考模式（顺序计时做全卷）。

## 七、Skill 流程（skills/bupt801/SKILL.md）
以后每年新卷照此执行：定位 待解析/<year> 两份PDF → Read逐页图像转录试卷 → SVG绘框图 → 辨认手写答案 → 独立解题写详细解析 → 交叉校验 → 标注章/知识点/易错点 → 生成 questions/<year>.js + papers.json + paper.html → 校验清单（30选择+8大题、总分150、编号连续、公式/图渲染、打印分页）→ 浏览器截图实测。
